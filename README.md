# DIGIUM — Next.js

Landing page digital agency untuk UMKM, menggunakan Next.js App Router, TypeScript, dan Poppins.

## Jalankan lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Deploy ke Vercel

1. Push folder ini ke repository GitHub `masbin5/digium`.
2. Buka https://vercel.com/new lalu import repository `masbin5/digium`.
3. Framework preset: Next.js. Biarkan Build Command dan Output Directory default.
4. Klik Deploy.

Semua tombol WhatsApp menggunakan nomor `6281774178707` dalam format internasional.
Harga dan item portofolio adalah konten awal yang perlu ditinjau sebelum publikasi.
